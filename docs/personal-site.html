The score blends demand, freshness, engagement decline, and search position into a single transparent priority signal.

Plain-words explainer: a backend is the server-side part of a website that receives requests and forwards or stores data. This demo does not need a backend because the browser reads the values you choose, runs the scoring logic instantly, and shows the result on the page. The data flow is simple: input values → JavaScript score function → visible output.
